title: Core concepts
description: Understand the runtime model that connects modules, providers, controllers, and Elysia.
---

AponiaJS separates application structure from the HTTP platform:

```text
Decorated classes
  -> immutable module definitions
  -> validated module graph
  -> singleton container
  -> Elysia plugins and routes
```
