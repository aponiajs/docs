AponiaJS adds modules, decorated controllers, request parameter decorators,
route validation, singleton dependency injection, and structured application
bootstrap to Elysia applications running on Bun.

<Callout title="Experimental release">
  AponiaJS `0.6.0-alpha.18` is under active development and is not recommended
  for production workloads. Check the current limitations before adopting it for
  a long-lived application.
</Callout>

## What you will build

The starter request path is intentionally small:

```text
main.ts
  -> AponiaFactory.create(AppModule)
  -> AppModule
  -> AppController
  -> AppService
```

`main.ts` owns bootstrap and listening. Modules define application boundaries,
controllers own routes, and injectable services own application behavior.

Continue with [your first route](/docs/getting-started/first-route) after creating or configuring a
project.
